# ЭЦП Подписание документов

Приложение для подписания документов в смарт-процессах Bitrix24 с помощью КриптоПро ЭЦП Browser plug-in.

## Возможности

- Кнопка **«Подписание»** в карточке смарт-процесса
- Два вида ЭЦП: PDF со штампом + откреплённый файл `.sig`
- Настройка полей для основного и ответного документа
- Генерация ответного документа через бизнес-процесс или генератор документов
- Выбор смарт-процессов в админ-настройках

## Требования

- КриптоПро CSP 5.0 на компьютере пользователя
- [КриптоПро ЭЦП Browser plug-in](https://www.cryptopro.ru/products/cades/plugin)
- Расширение CryptoPro для браузера

## Запуск локально

```bash
npm install
VIBE_API_KEY=vibe_api_... npm start
```

## Настройка

1. Откройте приложение через пункт меню (LEFT_MENU) или напрямую с `?page=settings`
2. Включите нужные смарт-процессы
3. Укажите поля: источник файла, PDF со штампом, откреплённая подпись
4. Для ответного документа — аналогичные поля + ID шаблона БП

## Подписание

1. Откройте карточку элемента смарт-процесса
2. Нажмите **«Подписание»**
3. Выберите сертификат и нажмите **«Подписать»**
